# DevOps-Lab04

## โครงการนี้คืออะไร
เว็บ Landing Page สำหรับแสดงข้อมูลการซ้อมระบบ IT Support ภายในองค์กร

เว็บไซต์นี้ออกแบบมาเพื่อสื่อถึงความพร้อมของทีมเทคโนโลยีในการรับมือกับปัญหาไอที เช่น การตรวจสอบระบบ การจัดการ Incident และการกู้คืนระบบให้กลับสู่สภาวะปกติได้อย่างรวดเร็วและมีประสิทธิภาพ

## วัตถุประสงค์
- สร้างหน้าเว็บที่มีลักษณะเป็นทางการและเหมาะสำหรับการนำเสนอภายในองค์กร
- แสดงข้อมูลสำคัญเกี่ยวกับการซ้อม IT Support อย่างชัดเจน
- สื่อให้เห็นว่าทีม IT มีความพร้อมในการตอบสนองต่อเหตุการณ์ต่าง ๆ
- ฝึกการออกแบบหน้าเว็บแบบ responsive ที่ใช้งานได้ดีทั้งบน desktop และ mobile

## คุณสมบัติของหน้าเว็บ
- Hero section ที่แสดงประเด็นหลักของการซ้อม
- ส่วนแสดงสถานะระบบและตัวชี้วัดสำคัญ เช่น SLA, incidents, tickets
- บล็อกสรุปหัวใจสำคัญของงาน IT Support
- กำหนดการซ้อมแบบลำดับเวลา
- รายการสิ่งที่ต้องเตรียมก่อนการซ้อม
- ช่องทางติดต่อสำหรับขอความช่วยเหลือ
- การออกแบบสไตล์ที่เป็นทางการและทันสมัย

## โครงสร้างไฟล์
- `index.html` : ไฟล์หลักที่เก็บโค้ด HTML และ CSS สำหรับหน้าเว็บ
- `README.md` : รายละเอียดและคำอธิบายโครงการ

## วิธีเปิดใช้งาน
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. หรือรันเว็บเซิร์ฟเวอร์แบบ local ด้วยคำสั่งต่อไปนี้:

```bash
cd "/Users/mac21/Desktop/Teacher Jo/DevOps-Lab04"
python3 -m http.server 8000
```

จากนั้นเปิด URL นี้ในเบราว์เซอร์:

```text
http://localhost:8000
```
